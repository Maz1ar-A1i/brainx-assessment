# CaptchaLab AI — Three-family synthetic benchmark

**Dataset seed:** `20261112`  
**Corpus:** 300 generated samples, balanced across three controlled families (100 each).  
**Solver stack:** OpenCV + NumPy + Pillow, CPU only.  
**External solver cost:** $0.00 for these local solvers. Optional Gemini fallback has separate free/paid usage-based cost estimation and is not used for this benchmark.

|---|---:|---:|---:|---:|---:|
| `synthetic_text` | 100 | 100 | 100.0% | 25.22 ms | 39.39 ms |
| `synthetic_arithmetic` | 100 | 100 | 100.0% | 10.61 ms | 16.46 ms |

Template warm-up occurs once; reported per-image latency is measured after solver warm-up. Values vary by CPU, operating system, installed fonts and system load. These results were measured in the current build environment, not on the candidate's Windows computer.

## Automatic family-identification check

The separate auto-classifier was evaluated on 100 additional deterministic seeds per family (not the 300 image-manifest rows): `synthetic_text` 100/100, `synthetic_arithmetic` 100/100, and `synthetic_image_grid` 100/100 (300/300 overall). These checks use the same documented generator grammar. Template similarity is a matching score, not a calibrated probability; the 3×3 grid family uses deterministic layout and cell-colour/shape evidence.

## Scope and limitations

This is an exact-match functional benchmark on images generated by the bundled controlled generators:

- Text: fixed five-slot alphanumeric transcription with known generator font/rotation/background families.
- Arithmetic: a fixed three-glyph digit/operator/digit expression followed by arithmetic evaluation.
- Image grid: 3×3 cells containing one filled shape from six known colours and three known geometric shapes; the prompt names the target colour and shape.

The benchmark validates the implementation and its supported synthetic grammar. It is **not** an independent benchmark of arbitrary fonts, unrestricted distorted text, real photographs, Google reCAPTCHA, hCaptcha, Cloudflare Turnstile, or any production provider challenge. The three synthetic families are not provider bypasses.

## Reproduce

Generate the corpus:

```powershell
.\.venv\Scripts\python.exe scripts\generate_synthetic_dataset.py --samples 300 --seed 20261112
```

Evaluate the existing manifest:

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_dataset.py --samples 300
```

Regenerate and benchmark in one command:

```powershell
.\.venv\Scripts\python.exe scripts\benchmark.py --samples 300 --regenerate --seed 20261112
```
